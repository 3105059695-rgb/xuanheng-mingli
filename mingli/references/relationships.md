# 八字婚恋与六亲：宫位、对象星和条件

在用户以八字问关系主题、伴侣支持或婚期时，先按 [八字内核](bazi.md) 核原局，再读本页。本专题可做单盘宫星分析、两人独立结构比较，以及完整期限内的运年/月条件复核。双盘比较是本 Skill 的现代组织方法；已核古籍支持其中的单盘规则，不据此冒称古籍有本版合婚体系，也不输出婚配分数或确定婚日。客户正文按 [白话报告](reporting.md) 写，解释决定本案结论的宫位或对象星；下面的完整规则留作核查依据。

## 先明确问的是什么

区分：自己的关系主题、已知两人的具体问题、对方的事实，还是某年某日结婚。生辰盘只能给本法下的关系条件解释；伴侣是否忠诚、是否已有另一段关系等，须用当事人的实际信息判断。

对象星约定与大运 `gender` 参数各自记录。用户已提供用于本次分析的性别参数时，可说明采用男命妻财、女命夫官杀的传统约定后继续分析，不要求小白先选择陌生术语。该约定仅是分析模型，不据此认定实际伴侣的性别，或分配现代关系中的主动、被动和经济角色。用户说明不适用或另有约定时再调整；缺少真正影响分析的参数才补问，不从姓名或称呼猜。没有适用的对象星映射时，先分析已知宫位与实际问题，将取星一项列待定。

## 已核规则与适用范围

主要底本为图书馆典藏《渊海子平 子平真诠》下册：[扫描本](https://upload.wikimedia.org/wikipedia/commons/e/e9/NTL-9900014380_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE_v.2.pdf)。PDF页从封面计数；印页是《子平真诠》内页码。

| 编号 | 实际核读 | 执行规则 |
|---|---|---|
| RL1 宫与星分开 | 《论宫分用神配六亲》，PDF128末—129，印页二七—二八 | 宫是四柱的位置，星是相对日主的十神符号；先各列一栏，再查两者如何配合。某星可在其他宫，日支也未必是财或官 |
| RL2 妻宫与妻星 | 《论妻子》，PDF129—130，印页二八—二九 | 男性旧模型以日支为妻宫，正文以干头之财论妻星。检查财透何干、根在何支、日支所藏是否有用；藏财只是盘面条件，不另算一个潜在伴侣 |
| RL3 同一符号因作用而异 | 《论妻子》，PDF130 | 妻宫坐财，遇需印之格可能损印；坐伤官则可在财格生财、在杀格制杀，须审伤官是否有力。生财、制杀的主语在此是日支所坐伤官，不是财。分别写清每个十神对月令结构的作用，再下有限结论 |
| RL4 旧女命取星 | 本底本PDF107，印页六，明确女以官为夫；[《三命通会》卷七《论女命》开头及“纯”“清”条件段转录](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷07#論女命) | 以克日主的官杀作对象星候选，区分官、杀路线，再查得时、通根、财是否生官杀，以及官杀生印、印再生身的链条。这里印助日主，不是印生官杀；印若过重，还须按原局审其泄官杀之气的影响。仅采用取星与作用条件，未内置该章全套女命格局 |
| RL5 合冲的条件 | 本底本PDF107—111，印页六—一〇 | 日主自己合财官，不直接按被别干合去论；隔位、争合、合冲并见仍需查位置与效力。合与冲都不能直接换算为婚姻事件 |
| RL6 运要回到整局 | 《论行运》，PDF131下半—133开头，印页三〇—三二 | 先立原局喜忌，再把运中每个干支配回完整八字；同一干或支、同为合冲，因本局位置、根气、制化而作用不同。不得把某人的喜财年，移作另一人的喜年 |
| RL7 原局与后来的条件分开 | 《论行运成格变格》，PDF133，印页三二 | 原局未全的结构可能由运补足，已有结构也可能被运改变。先写原局缺什么，再写该运补了什么、同时破坏什么；把“成格条件”与“发生婚姻事件”分开 |
| RL8 支藏、透出、通根各记一笔 | 《论支中喜忌逢运透清》，PDF133下半—134上半，印页三二—三三 | 库中所藏与运中透清不同；干要看坐支及全局有没有根，支要看天干怎样发用。对象星从藏到透只构成新条件，仍须回看RL3/RL6，不自动记作婚讯 |

RL3是婚恋专题本身的宫星与格局配合，不是把事业用语换成“伴侣”。例如“财能生官”只能支持这条传统结构有相助条件；它没有证明现实对象会给钱、会体贴或会服从。

六亲定位只采用RL1实际写到的范围：

| 层次 | 本篇旧文分配 | 使用边界 |
|---|---|---|
| 宫分 | 年对应祖辈，月对应父辈，日对应配偶，时对应后代；婚恋重点核日支 | 月宫与母亲星是不同概念；一个位置不能替代亲属实际资料 |
| 十神六亲 | 正印对应母，偏财对应父，比肩对应兄弟，正财对应妻，官杀对应子女 | 这是本篇男性叙述下的六亲表，不是全部现代家庭的通用映射。女命旁证另以“我生者”为子，不能混成同一张表 |

同一个财可以在不同问题中被赋予不同象义，不能因此认定父亲、伴侣或钱财在现实里发生了某种事件。父母兄弟仅作以上定位；本专题不据星的存亡、旺衰推人数、寿命、疾病或血缘。旧文的妻妾、品行等级与生育断语保留为历史文本，不应用于真人评价。

## 先各自立案，再比较两人

完成每人的下面四格，才作双盘判断；单人问婚恋时只做其一。每格只保留会影响本次问题的内容。

| 核查格 | 必须落到盘上的记录 | 完成条件 |
|---|---|---|
| 输入与宫星 | 四柱、出生误差、日界；日支和藏干；对象星逐处记明透/支藏/不见/未知 | 两人的参数不互借；时辰未知留候选；原局不见对象星不推无婚 |
| 原局路线 | 月令主线、日主承受条件、宫星实际支持或损害哪条路线 | 至少一条最强支持和一条最强反证；不能只写“妻星旺”“夫星清” |
| 关键取舍 | 支持有无根和位置条件；合冲是否生效；哪个条件一变会改判 | 选择本案主线，并写未采用另一解释的具体原因；不能同时取互相破坏的好处 |
| 现实核对 | 已知关系状态、双方意愿、正在争执的具体安排及信息提供者 | 盘中符号与现实对象的行为各留来源，待证的行为保持待证 |

双人比较按下面顺序执行，保留双方独立结论：

1. **同题比较。** 先固定共同目标，如“在期限前双方自愿完成登记”；相识、复合、订婚、同居、登记分别留标准。不把一个人想结婚写成两人都愿意。
2. **原局比较。** 对照双方宫星对各自原局的作用。A盘所需之印，不会因B盘印多而变成A盘已有的根；两盘不能拼成三合局或合化局。把“互补”写成现代相处建议时，须用双方已陈述的习惯和分工支持。
3. **同期比较。** 依下节检查同一段日历中两人的条件。A较有利而B有明显牵制，记录为双方条件不同步；不得平均成“中等合适”。两人都有支持也不等于已取得对方同意。
4. **交付。** 先给有条件的推进/暂缓建议，再给最关键的两三条可见依据。术数理由说明规则与反证，现实建议另标事实来源。没有经过核查的传统规则可从符号直接推到登记事件时，交付“条件与窗口审核”，不伪造确定婚期。

跨盘的日干十神和日支六合/六冲配对，可以列为**符号并列观察**。它们不等于人格、感情深浅、忠诚或终局；两人同为丙日不证明性格一样，两人日支无合冲也不证明没缘分。年支属相只占一项输入，不能替代以上过程。

## 婚恋时间窗口：先查完整期限，再筛选

这里的“窗口”是**传统结构条件变化的时段**。从这一步到“某月会登记”之间还缺事件证据，不能靠术语省略。首次答复冻结目标及主判断，回访按 [留验规范](validation.md) 新建版本。

1. **先定基准。** 保存两人的原局路线、当前运候选及原局最强反证。排运参数、起运算法、出生误差两端都分别计算；不能凭年份表将1月1日当作交运日。
2. **列全期限。** 依十二节拆分每段年/月干支；立春同时检查换年和换月。保留首尾不满整月的区间与未见明显宫星配对的区间。原题按公历年月提出时，显示公历日期，不把农历初一作换月。
3. **逐人核作用。** 对每段写三个短项：对象星是否透出/得根及其代价；日支及对象星根所在支有什么配对、条件是否成立；所取运年/月干支是否改变原局主线。先按RL6处理整局，再解释RL1—RL4宫星，不能只累计吉凶符号。
4. **保留反向节点。** 例如卯月合戌日支，若同时冲酉月令财根，须并列“宫有合的配对”和“财根受冲的配对”，判断合冲效力后才取舍。下个月使支持消退或反证增强，同样列出；不能只挑一个有利月。
5. **运界分路。** 后续十年交运日未核定时，交运标签年内按前/后两运分别审核。只有结论对两路都成立，才可给共同判断；不同就把缩窗限制写到正文。出生误差即使不改四柱，也可能改变起运日期甚至起运标签年，不能省略。
6. **筛入正文。** 仅保留两三段最影响结论的节点，讲清“什么条件增加、什么牵制仍在”。全部分段及无明显变化的区间留核验摘要。只有本法的合冲候选、未完成旺衰/取用/运界审核时，输出候选并说明待核项，不评“最佳婚月”。

内部核验每段用一行：`时间｜A的作用＋反证｜B的作用＋反证｜双方条件一致/不同步/未决｜对主判断的影响`。这里“一致”只指已审核的传统条件方向，不是适配评分。

## 自动核查两盘与期限

`scripts/relationship_review.py` 复用固定版本排盘：两人四柱/藏干/对象星并列，保留原输入；按十二节覆盖明确期限，列年/月十神、明透与支藏对象星、对原局的五合/六合/六冲/同字候选。它不执行合化、三合、刑害、旺衰或格局成败；必要时按内核继续人工规则审核，不能把“未列配对”写成“没有其他作用”。

每人显式填写 `object_star_model`：`wealth`（传统妻财）、`officer-killing`（传统官杀）、`unassigned`（不采用该映射）。它与各人的 `gender` / `yun_sect` 排运参数独立。出生时刻或误差未知、误差实际跨柱界时，工具停止唯一双盘流程，改走分别候选盘审核；不补中午。晚子时已明确日界时，按该口径计算并保留另一口径差异；不把两个日主的十神混用。历法输入按 [时制说明](calendar.md) 先归一，计算仍使用确认过的UTC+8标准时。

期限采用 `[start,end)`，起点包含、终点不包含。工具逐节覆盖最多732日；更长期限分期。客户给出的截止秒如也需纳入，先明示把工具的排他终点加一秒。输出保留中心和出生误差两端的起运；`label_interior` 仅指这些样本落在相同运的标签内部，`unresolved_boundary` 表示至少一条路径涉及运界或候选分歧。它们都不等于已独立核定交运时刻。

可直接运行的虚构双人输入、白话报告与完整核验摘要见 [双人婚恋窗口示例](relationship-example.md)。运行方式：

```sh
.venv/bin/python scripts/relationship_review.py --input /path/to/couple-input.json
```

只需要单盘解读或时辰未知时，无须强行使用双人脚本。例如已知三柱癸亥、甲子、乙亥，时刻不详，不能据三柱无庚辛断定无婚；未知时柱可能改对象星是否出现。能交付的是已确认柱的宫星条件及缺项影响，不能承诺补齐时刻就能算出准确婚日。

以上程序和古籍条件提升的是可复算与规则一致性。虚构样例不证明预测准确或客户愿意付费；原文妻妾、品行等级、生育和寿夭断语不转作真人评价。
