# 核验与推演：专业依据要可追查

本页是本skill的工作规范。所有求测使用；具体规则仍按八字、六爻、梅花或民间分支。目标是在明确采用的方法内，核对输入、计算与解释，及时纠正实际错误；不能保证所有流派都会得出同一结论。

## 把四类内容分清

- **用户提供的事实**：出生或起卦记录、交易背景、实际选项、期限和金额等，保留来源与信息截止点。缺失字段、执行者假设单独标记，不写成用户已确认。
- **排盘计算**：四柱、干支、卦爻、六亲、动变、起运等可复算结果，用实际执行输出，不凭记忆填表。
- **传统规则判断**：规则在本盘、本题及期限内是否成立，说明适用条件和反证。配对、空、冲等计算标签不直接等于作用有效，更不是现实事实。
- **现实情境解释**：将上述传统判断结合本次已知情境作类比或推断，标明解释身份；不能据此确认交易内幕、财务或信用。

现实建议另标其依据的用户事实或必要假设，不把情境解释当作已核事实。大众正文按 [八条规范](reporting.md) 区分来源；无需为了分类给短问写四篇文章。

## 先查会改变结果的地方

输入原文与归一化资料分别保留：历别、时区/日界、误差、投掷方向与模拟身份。一旦客户更正输入，追查受影响的结论；生日时刻改变可能牵动时柱、取用及起运，不只改表头。

实际计算出现错误，先修复或说明具体未能完成的部分。独立核盘须真正使用另一份来源或另一套实现；重复运行同一个库、它的派生库或其上游自测，只能称复算/回归。边界处按对应分支重算；库显示到秒不等于外部验证到秒。

来源按 [台账](sources.md) 的实际层级使用。馆藏目录只证明书目；转录有古书标题也可能夹现代注。引用到哪条规则就核到相应段落，保留版次、卷章或页码；疑字和来源未核不靠肯定语气消除。既有规则已核且本次没有新歧义时，无需每次重搜全书。

## 四术分开推演

| 主法 | 必须完成的推演主线 | 易错的参照 |
|---|---|---|
| 八字 | 月令取用、顺逆与相神、成败救应、根气/气候、运年怎样改变原结构 | 格局用神与扶抑用神分开；藏而未透不能自动当明干；配对、合去与合化分层 |
| 六爻 | 问事取用、世应/元忌、日月与动静施力、空破合冲及本位动变、期限内的结论 | 六亲参本宫；世应代表固定位置；变爻作用范围按选定原文，不任意横向生克 |
| 梅花 | 固定原体，比较本用、互、变，加入有依据的旺衰和问题情境 | 原体不因结果有利而改设；物数、时数与余数口径原样记录 |
| 小六壬/民俗 | 版本、输入与起点计数、落位/结果、该版本允许的解释 | 时间法与现代三数法分开；模拟不冒充实掷；寺方流程不推广为全国统一规则 |

规则同名但含义不同，不跨体系互换。支持与破坏并见时，比较具体施力条件，不数吉凶词，也不创造统一评分。若差异来自流派，说明本次采用哪一派及另一派会改变什么；不要把个人偏好叫作唯一正解。

## 每个重要判断留一条证据摘要

| 项目 | 留下什么 |
|---|---|
| 所问及期限 | 对象、期限起止和口径、目标金额/不适用、成功标准；缺失与假设明示 |
| 四类来源 | 用户事实、排盘计算、传统规则判断、现实情境解释分别标记，不能互换身份 |
| 采用规则 | 具体章段或已明示的工作约定，以及本案适用条件 |
| 当前裁定 | 规则成立、有条件成立、不成立或具体待定项 |
| 最强反证 | 哪项可能改变结论；为何仍保留当前判断或必须分支 |
| 全期限节点 | 节点及作用、能解除/新增哪项条件、是否足以改判，以及日期缺失等未核范围 |
| 结果与版本 | 主/辅分别编号，保留原句、信息截止点、金额/期限/标准及后续证据；标准未定即标未定 |
| 用户读到的话 | 对应的白话建议及适用条件，不能强于依据 |
| 实际核验 | 本次确实做过什么，哪些只是沿用已核规则，哪些仍未独立验证 |

不要只记录支持。给出反向证据后也要完成裁定：能选主线就明确选择，确实不能则点明分叉，而不是将所有可能性同时写成肯定句。应期必须回到具体解除条件和已核日历，不能从数字或卦名随意造日期。

## 出具前复核

逐句检查会改变客户行动的主判断，确保盘面、规则、期限与建议对应；只覆盖实际有依据的方法和专题。发现疑点按影响处理：算错则更正；关键规则未能核实则缩小那项结论；纯称谓差异可注明，不重排整盘。不得为了“看起来无错”删掉争议或伪装已经外部验证。

复杂报告、关键输入更正、新增断法或新修计算逻辑时，可请另一位执行者独立复核。AI交叉检查如实称AI复核，不称人类大师认证；自测与真实预测效果也分开。交付正文按 [白话报告](reporting.md) 编写。

复盘保留原输入、原判断、原定金额与期限、成功标准和后来的事实；主结果与辅助结果分别记录，辅助发生不替代主结果。新信息或修正另建版本，旧字段缺失不追填成原已知，不事后改变成功标准。承认未获支持，不用用户心诚与否解释失败。
