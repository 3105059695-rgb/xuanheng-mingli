# 梅花内核：体用、旺衰、互变、类象

本分支采用《梅花易数》公开传本的数起卦＋体用框架。公式与可执行命令在 [divination.md](divination.md)。本页是内部推演步骤，不是古籍逐字算法；客户表达按[大众版规范](reporting.md)先回答再解释，先固定对象、期限与主成功标准。

## 1. 固定主客

单动爻所在三爻经卦为用，另一经卦为体。体代表所占主体，用代表这一次所问的事或对方；先写明实际对应。原体在本卦、互卦、变卦的比较中保持不变。不能每换一卦就把有利的一方重新叫体。

脚本给出 `body`、`use`、`body_position`、`use_position` 和 `relations`。比互卦时，`relation` 字段中的“用”只是被比较经卦的角色简称，原用位置没有被更换。给小白解释时，将其说成“这一个参照卦对原主体是帮助、耗力还是约束”，不要让用户误以为主体一直变动。六爻纳甲的宫五行和六亲不用于替代这里的体用五行。

## 2. 定基本作用

| 方向 | 主轴意义 | 必须继续检查 |
|---|---|---|
| 用生体 | 事情/对方对主体形成生助 | 生助之卦有无力量、是否被其他卦阻断 |
| 体生用 | 主体向事情付出，存在耗泄 | 付出是否为问题本身所需、主体能否承受 |
| 体克用 | 主体可制约所问对象 | 体是否有力、是否因此迟滞，不能只看“克” |
| 用克体 | 所问对象向主体形成制约 | 体旺衰、有无生体之卦、变后是否转解 |
| 比和 | 双方同气，较少此项生克冲突 | 其他卦和实际问题是否仍有阻力 |

上述五向关系及问事分法可核 [卷二“人事占第二”“求谋占第八”等](https://zh.wikisource.org/wiki/梅花易數/卷二)。传统文本的直接吉凶语用于辨识该法方向，实际个案要把作用条件说全。

## 3. 辨时令与生助路径

体、用、两互卦分别记五行：乾兑金、震巽木、离火、坎水、艮坤土。卷一列木春、火夏、金秋、水冬及土于辰戌丑未月的旺时；执行时注明本次月份/节令如何取得。不能以阴历几月替代所有流派的节令月份。

先写体是否得时令与同类支持，再看克体之卦是否有来源生助；同样，生体之卦若受克，其救应要打条件。这一步采用作用路径，不按“几个吉卦抵几个凶卦”计票。没有时间信息时，明确旺衰这一项未定，仍可解释已经算出的生克方向。

## 4. 读变化，不重设主体

按原体分别比较本用、两互卦、变用。[卷二“体用总诀”](https://zh.wikisource.org/wiki/梅花易數/卷二#體用總訣)明确以互卦为事情中间、变卦为末后，并讨论用吉变凶或用凶变吉。因此本用、互、变可以读成当前作用、过程和变化后的倾向；这是有传本文本依据的阶段框架。逐项列表是本版呈现方式，具体经过几日几月并不由这个框架自动给出。

- 本用克体、变用生体：支持“开始受制，变化后出现缓解”的传统倾向；若互卦继续生起克体之物，须说缓解之前仍有压力。
- 本用生体、变用克体：支持“开始有助，后续条件转紧”；检查变动由哪一爻发生，避免笼统叫大吉。
- 本用与变用均生体：同方向支持较一致；仍需确认体是否承受、何种问事映射适用。
- 本用与变用均克体：此项阻力贯穿；有救应则列救应条件，没有则不要用漂亮话取消它。

纯乾坤的互卦采用哪条约定由脚本显式输出，不能拿机械互卦结果与“互其变卦”规则混解。默认是对本次之卦取一次中爻；初爻或上爻动时，中间四爻不变，互卦仍可能是纯乾坤。以 `mutual_policy.used_changed_hexagram` 核对取材来源，而不是只看最后互卦名字猜流程。

## 5. 以问题约束类象

类象用于已完成体用后细化事物特征。先记录可用线索和候选解释，再用已知情境排除不合适者。用户没说过的细节不能伪称被独立算出。

| 问事 | 先对应什么 | 细化时检查什么 |
|---|---|---|
| 求谋/合作 | 体为我方，用为所谋事项/对方 | 何处受助、何处耗力，条件落实是否有先后 |
| 求财/交易 | 体为求测主体，用为所求财事 | 可得、需投入或受制的传统方向；不转成投资指令 |
| 寻物 | 体为寻找主体，用为所失之物 | 变卦类象可提供检索线索，但需与失物场所事实相容 |
| 闻声辨物 | 先依据材质、形状等类象列候选 | 由发生时地与对方已说明的用途缩小范围 |

应期须交代采用卦气还是数时规则，列候选窗口和条件。候选窗口与变化阶段须对照整个原定期限；日期或时间单位未核，不能把后期转助自动写成期内达标。无法说明机制时不填写确定日期，并在主结论中保留未核范围。传统外应只使用用户实际记录的场景，不从联网随机找一条新闻来替代外应。

## 两个贯通示例

### 观梅结构：革初动之咸

原体兑金，本用离火克体；互下巽木可生火，互上乾金与体同气；变用艮土转为生体。于是主轴不是“革代表改变”，而是“本用构成压力，中间有增压路径，变用带来生助”。这支持有条件的“先受制、后有缓和”。卷一原故事进一步使用少女、股等类象，但本次一般求测不能照搬那段具体伤害情节。

### 邻夜扣门结构：姤四动之巽

第一段1声、第二段5声、酉时10，得上乾下巽；四爻动，体巽木，用乾金克体，互乾，变用巽与体比和。古例再用金木、长短及冬夜借物用途讨论器物候选。操作启示是：先保留能够符合材质与形制的多个物件，再依据已经知道的用途筛选，不能把猜中一件物品当成普遍命运准确率。

两例的算式见 [卷一“观梅占”“邻夜扣门借物占”](https://zh.wikisource.org/wiki/梅花易數/卷一)；方法内对情境与变通的讨论见 [卷二“心易占卜玄机”“占卜论理诀”](https://zh.wikisource.org/wiki/梅花易數/卷二)。本版已将这两例及牡丹例纳入计算回归。
