# 起卦操作与公式

## 三钱法

在投掷前明确两面的名称与分值。本版示例字面2、背面3；若已投掷，采用当时约定，不倒换结果。三枚相加，6老阴变阳、7少阳不变、8少阴不变、9老阳变阴。投六次，第一次为初爻在最下，第六次为上爻。保留每次三枚结果。

```bash
python3 scripts/divination.py coins 223 233 333 233 223 222
python3 scripts/divination.py lines 7 8 9 8 7 6
```

记录本卦、动爻、之卦后，六爻求测继续执行 [六爻内核](liuyao.md) 的纳甲与断法。数字与老少阴阳关系见 [《五经说·揲蓍说》](https://www.shidianguji.com/zh/book/SK0510/chapter/1jurmpedci9ej)；钱币背字与顺序参照 [《增删卜易》操作转录](https://zh.wikisource.org/zh-hans/增刪卜易/2)，其中现代说明与古文有层次区别。

用户要求代为随机起卦时，可运行 `python3 scripts/divination.py simulate`，明确是计算机随机模拟，并保留第一次结果。三钱分布不是蓍草筮法分布。

`lines`、`coins`、两段声音和物数命令都可传 `--provenance user-reported|simulated|derived`：分别表示用户报告、模拟输入、由已有记录推导。默认是用户报告；该字段只标记来源，不替用户投掷或产生声音。复算模拟结果必须仍传 `simulated`，保留六组三钱或原声数/物数，不能只留一个卦名。`simulate`直接返回可重放的六组三钱记录、`provenance=simulated`及模拟说明。

## 梅花共用约定

核心起数来自 [《梅花易数》卷一](https://zh.wikisource.org/wiki/梅花易數/卷一) 的“周易卦数”“卦以八除”“爻以六除”及具体占例。采用乾1、兑2、离3、震4、巽5、坎6、艮7、坤8；余0归8，动爻余0归6，爻自下而上。

输入的年支和时支序数从子1至亥12。原文给年支数，没有完整规定现代日界和闰月制度。本版时间法默认从核实的农历年取年支、民用零时分农历日；其他约定须具名保存。八字立春年柱不能直接替代此参数。

`--mutual-policy changed-for-pure` 是本版默认：原卦为纯乾或纯坤时，采用卷一“乾坤无互，互其变卦”这一条。始终同时输出机械互卦，避免隐式切换。若用户采用只取本卦中爻的版本，使用 `--mutual-policy mechanical`。非纯乾坤时，下互取2/3/4爻，上互取3/4/5爻。

“互其变卦”在本实现中是：先改变本次唯一动爻，再对之卦取一次2/3/4与3/4/5爻；不反复求互直到出现别的卦。纯乾坤若只动初爻或上爻，中间四爻不变，所得互卦仍可为乾或坤。这不是计算失败。两互经卦分别与原体比较，互卦的六十四卦名只用于检索、核对，不成为新增的一票吉凶。

### 一、年月日时

A=年支序数＋农历月＋日；A除8取上卦。B=A＋时支序数；B除8取下卦，B除6定动爻。

```bash
python3 scripts/divination.py meihua-time --year-branch 5 --lunar-month 12 --lunar-day 17 --hour-branch 9 --leap-month no --calendar-source '观梅原例' --day-boundary supplied-lunar-date
```

卷一“观梅占”核验：34、43→革，初动，变咸，互姤。另“牡丹占”：巳年三月十六卯时，25、29→姤，五动，变鼎，互乾。故事的记载与算式的正确性分别看待。

年月日须先按 [日期核验](calendar.md) 检查；需要公农历转换或实际月天数时使用 `scripts/calendar_input.py`。起卦脚本的1—30日范围校验不能证明该月真的有30日。日期助手确认闰月存在后，仍未决定本法怎样取数；本法当前拒绝自动处理闰月，须先确定版本后另算。

传实际时刻时，把历表/换算来源保存在 `--calendar-source`，并记录 `--day-boundary midnight`（民用零时）或 `zi-start`（子初）；只有已给定农历数字、没有要转换的时刻才保留 `supplied-lunar-date`。这些参数只记录前置校历口径，不会自动增加一天、校验年支或处理月末。换日争议导致输入不同，应分别算出候选结果。

### 二、两段声音

以已记录的第一段声数作上卦、第二段作下卦；两段原数与时支数相加定动爻。依据卷一“邻夜扣门借物占”这一个具体取法，不能与同卷单段声音的另一表述混算。原例为1声与5声，原数和约后卦序相同，不能用该例证明大于8声时只有一种传统算法；本版超过8声仍保留原数，并以 `meihua-two-sound-groups-raw-v1` 记录这项工作约定。

```bash
python3 scripts/divination.py meihua-sounds 1 5 --hour-branch 10
```

一次声、随后五次声、酉时10，总数16，得姤、四爻动、变巽、互乾。声音的分段在求得结果前记录；不要为了得到某卦重新划分。

### 三、可数之物

所见物数作上卦，时支作下卦。卷一“物数占例”的“卦数”有原数与约后卦序的解释空间，程序让差异显式化：

```bash
python3 scripts/divination.py meihua-objects 17 --hour-branch 3 --moving-basis raw
python3 scripts/divination.py meihua-objects 17 --hour-branch 3 --moving-basis reduced
```

`raw` 为本版工作默认：17+3定爻；`reduced` 则用约后的**物卦序**1加原时支3定爻。两者始终保留原时支序数：例如17物、酉时10，`raw`为17+10=27取三爻；`reduced`为1+10=11取五爻，酉时不能在这里改成2。下卦的卦序仍按10除8取兑，两种除数各有用途。

`reduced`的规则版本为 `meihua-object-reduced-plus-hour-v2`。这只界定本 skill 如何实现“卦数”的约数解释，不宣称消除了所有传本分歧。两种口径的原数、取爻分量和版本须随结果保存。

## 从卦进入判断

梅花起卦完成后必须读 [meihua.md](meihua.md)，完成体用、时令、互变与类别判断。仅解释“革是变化”“咸是感应”不能算完成梅花断卦。

用户明确只读《周易》卦爻辞时，按对应文本作义理解读；不要称已完成六爻纳甲或梅花体用。多动爻用何种爻辞选择法须说明，不能临时编一套唯一规则。
