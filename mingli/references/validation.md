# 真人试用与结果验证

仅在用户要求试运营、验证预测或检查收费效果时读取。普通求测继续按 [核验与推演](core.md)、[咨询交付](consultation.md) 和 [白话报告](reporting.md) 执行。本页是现代评估工作约定，不是古法，也不为传统预测背书。

实际执行可复制 [单案复核记录](../assets/review-record.md)，同时交付匿名原始输入、计算输出、首次报告和所用规则版本。表内分别记录专业复核与读者复述，避免用模型自评填补真人证据。需要请业内人士审查时，先让对方独立判断，再比对报告；将计算错误、规则用错与流派差异分别处理。尚未取得真人记录，就把它列为待验证，不能因工具和表格已准备好而宣布通过。

## 先确定要验证哪一件事

四项分别留记录，不合成“准确率”或总分：

| 项目 | 可采用的证据 | 不能替代它的证据 |
|---|---|---|
| 计算正确 | 输入与口径、实际盘式、独立历书或实现的比对、差异处理 | 同库重复运行、用户觉得像 |
| 客户理解与决策新增价值 | 客户能复述主判断、下一步及改判条件；指出新增信息、未解决问题和实际使用情况 | 报告长、术语多、笼统满意 |
| 事实预测 | 事前固定的事件、条件、期限和判定标准，与到期事实比对 | 已知背景、性格共鸣、建议被采纳、愿意付费 |
| 实际付款 | 各价格下的真实报价、支付、退付记录与原因 | 商家标价、口头愿付、免费好评、模拟评价 |

合成占例、模拟回访与计算回归不进入真实预测、客户满意或付款统计；不得由它们生成命中率或数值概率。没有记录支持的数字不编造，真实记录中的描述性占比也不是个案预测概率。

尚无真实反馈时如实记为 0。人民币 1000 元仅在经营者提出时记为目标价，不视为已获客户接受；实际价格及交付条款分别确认。准备材料不等于已经邀约、收款或安排回访。

## 开始一批试用

可先用 10 名知情自愿者作为方便发现问题的一批；这是便利样本，不是统计样本量依据。人数可按实际条件调整，不设“若干人满意即证明有效”的门槛。

为每人建匿名编号，按方法收必要输入；默认无需完整姓名或住址。先向参与者说明有 AI 辅助、采用已核出处的古籍规则、无法保证预测；把主问题、交付内容、追问范围、真实价格及未完成处理写成实际约定。

开始前记录客户原本的选择、已有理由和最想解决的问题。结束后让客户自己复述结论与行动，再记录哪项内容是新增的、哪项仍没帮助。先保留原话，再由执行者对照报告标出理解差异，避免只问“准不准、满意吗”。

完成标准是每项实际开展的检查都有记录；未做项标未做。真实用户联系、收费和提醒按已有授权另行执行，不能由本页推定授权。

## 冻结预测与信息范围

交付前保存当时的原始输入、已知背景、计算版本、完整答复和信息截止时间。为每项可判定预测编号；一次报告有多项预测时逐项登记，避免只挑最有利的一句。

| 必填项 | 写法 |
|---|---|
| 原句与版本 | 原文留存，注明首次告知客户的时间 |
| 事件与对象 | 哪件可观察的事发生或不发生；排除已经知道的事实 |
| 结果层级与金额 | 主结果/辅助结果分别编号；记录金额币种、全额/部分或不适用，缺失与假设明示 |
| 判断方向 | 明确预期发生、不发生，或有可检验先后关系的变化 |
| 条件 | 有条件预测须预先固定触发事件、触发截止点及核实方式；无条件就记无 |
| 期限 | 起止时刻、包含范围与时区；条件须在结果判断所需时点之前成立 |
| 判定标准 | 什么证据算支持、什么算不支持；无法核实怎样记录 |
| 信息与行动 | 哪些背景已知；客户后续采取了什么行动 |

主结果与辅助结果各有原句、期限、标准和到期状态；对账、承诺、部分到账不能替代全额达标，辅助成立不能把主结果不支持改记整体命中。旧记录未固定金额或成功标准的字段保持缺失，不在事后补成已知。

只说“有可能、注意一下、好坏都有”的话不具备明确预测方向，归为传统主题或建议，不纳入命中统计。先难后易要分别固定两阶段事件及期限；只出现其中一段不能算整条支持。

“两周内偏能收到书面通知”已经选择了事件方向，可以按事先固定的标准留验；“偏能”不是免记不支持的条件，也不是已校准的数值概率。判定对象仍是书面通知，电话意向不替代它。仅把结果改写进前提的句子（如“正式批准并发函后会收到发函”）没有独立预测内容，单列为流程说明。

有条件预测按原条件判断：条件成立后结果相反，记不支持；条件未触发，单列未触发，不算命中。条件含糊时先说明该句不可判定，不在结果出现后补条件。不得为相反结果各找一种解释，使每种结果都成为支持。

新背景、新出生资料或新判断另建带时间的版本；原输入和原断仍保留。注明修订来自输入纠正、现实信息增加、计算错误或解释改变；修订后的符合不能追认原断命中；换对象、改金额或标准、延长期限均另建记录，保留旧版本。客户在建议后采取行动，单独记录，建议奏效与事前预测是两项结果。

## 到期与汇总

按冻结的标准先判状态，再收满意度评价。证据可以是客户如实记录的结果或其自愿提供的必要材料；无需为核验索取无关隐私。

| 状态 | 使用条件 |
|---|---|
| 支持 | 到期或事件已完成，预设条件满足，证据符合预设结果 |
| 不支持 | 预设条件满足但结果相反，或截止时应发生的事件未发生 |
| 条件未触发 | 触发期限已过且预设条件未发生；不计为支持 |
| 未到期 | 尚待原定事件或条件截止时间；不能提前判定“不发生” |
| 失访 | 到核查时未得到参与者反馈 |
| 无法核实 | 得到部分反馈但不足以依预设标准裁定，注明缺项 |

没有明确预测的案例单列“本案无可判定预测”，仍可评价计算、理解和建议。原本不可判定的句子不强行分入支持或不支持。

汇总同时给参与者人数、预测条目总数及各状态数量；一人多条预测仍属同一案例，不冒称独立样本。保留原始负例、未触发、未到期、失访及无法核实，不能将它们静默移出展示范围。确需展示已判条目的支持占比时，注明分母只含支持与不支持，并同时列全量状态；该描述不是预测效力证据。

## 检查咨询带来的新增价值

基础对照是只使用相同现实背景、没有术数推演的普通建议。可请同意参与比较的用户读匿名 A/B 两稿：篇幅和问题范围相近，顺序随机，资料截止一致。事先如实说明两稿来源不同，阅读后揭示对应方法；不把普通建议伪称已排盘，也不把匿名当作完全盲法。

请客户分别指出：哪一稿新增了可核实的问题、为何更有助于选择、哪句不适用、下一步是否可执行。允许两稿同样有用或均无帮助；支持偏好须落到具体内容。对照稿应认真回答问题，不故意写弱来制造优势。

这种比较可发现解释和决策支持问题，不能验证事实预测。若要研究预测准确率，需要另外预先设计合适对照、基准发生率、评价方式和样本量，并处理多重预测、条件选择、用户行动及失访；不从 10 人试用宣称准确。

## 付费记录与本轮结论

按实际价格分别列报价人数、实际付款人数、实收、退付、净收和主要理由；保留未购买者反馈，缺反馈就标缺失。只统计真实行为，优惠或不同交付另列，避免把价格变化混成同一接受率。

本轮结论分别回答：发现了哪些计算问题、客户哪里没听懂、增加了什么可用内容、预测还有多少待核、实际支付怎样。由证据决定修改哪一项，不用付费证明预测、不用预测支持掩盖交付缺项。没有发生的试用、评价和付款保持为 0，不填示意好评。
