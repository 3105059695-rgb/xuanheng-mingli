# 六爻纳甲：装盘、取用、判断施力

用户选六爻纳甲，或需检查完整盘时读本页。起卦原始操作见 [起卦](divination.md)。默认以《增删卜易》的用神、日月、动变、飞伏体系研判；八宫与纳甲表以《卜筮正宗》作交叉核对。这里的“工作规则”是为执行与复核整理的次序，不冒称原书逐字算法。

## 1. 把盘装出来

最低输入：一件事、提问期限、初爻至上爻六个 6/7/8/9，以及已核实的**日干支、节令月建**。月建按节交月，不直接取农历月名。时区、当地历史时制、换日口径由 [历法校验](calendar.md) 处理后传入，脚本不从电脑日期补齐。

```bash
python3 scripts/liuyao.py 7 7 7 9 7 7 --day-ganzhi 戊申 --month-branch 辰 --use-relative 父母
python3 scripts/liuyao.py 7 8 7 8 8 7 --day-ganzhi 壬辰 --month-branch 卯 --topic document
```

脚本无第三方依赖，路径以 skill 目录为基准。输出含本之卦、八宫宫五行、世应、六亲、纳甲干支、六神、旬空、月破、日冲、动爻关系、回头生克合冲、缺亲伏神及用神候选。展示盘时可上爻在上；输入与 JSON 始终初爻在前。

输入来源用 `--provenance user-reported|simulated|derived` 声明，默认 `user-reported` 仅表示用户提供记录，不表示程序目击实投。模拟三钱转入纳甲时，使用已生成的六个爻值并传 `--provenance simulated`；程序不重抽。接口 `chart(..., provenance="simulated")` 会把标记传给共用起卦并保存在最终 JSON 的 `provenance` 中，旧位置参数保持兼容。原始六组三钱与来源记录仍须随盘保留；没有原始记录时不编造物理投掷过程。

### 装盘不变量

- 宫五行是安六亲的“我”，既不是日干，也不是世爻五行；同我为兄弟，我生子孙，我克妻财，克我官鬼，生我父母。
- **变爻安六亲仍用本卦宫五行**。之卦自身宫名仅供辨卦，不能替换参照系。静爻旁的之卦排盘是对照资料，不是额外动爻。依据 [动变章第七](https://zh.wikisource.org/wiki/增刪卜易/7)。
- 八宫各序的世位依次为 6、1、2、3、4、5、4、3；应在相隔三位处。依据 [世应章第六](https://zh.wikisource.org/wiki/增刪卜易/6) 与 [八宫图](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy04.html)。
- 所有内外卦纳支都从下向上排；阴卦也一样。乾内甲外壬，坤内乙外癸，震庚、巽辛、坎戊、离己、艮丙、兑丁。支序用 [浑天甲子章第四](https://zh.wikisource.org/wiki/增刪卜易/4)；干支配合与 [《卜筮正宗》纳甲装卦](https://www.quanxue.cn/qt_mingxiang/boshi/boshi07.html) 交核。后者有字误及易误读表头，实际核对说明见下文版本边界。

## 2. 先取用，再解释盘面

完成标准：用一句话写清“问什么，因此以哪一爻或哪一类六亲为主”，同时给出该类在盘中的全部位置。先按事类取用，随后才看吉凶，不因为某爻漂亮就改用神。

| 问题 | 主取用 | 随后核对 |
|---|---|---|
| 求职、职位、晋升 | 官鬼 | 世爻承接情况；录用文书、证书看父母；工资款项另取妻财 |
| 应收款、买卖所得 | 妻财 | 世爻、财源子孙、兄弟是否形成有效克财；合伙对方可看应 |
| 契约、证件、通知 | 父母 | 世与父母的关系；官鬼是否支持手续；对应现实文件状态 |
| 双方互动、合作 | 世为本人，应为对方 | 先明谁问谁；只把生克合冲译作互动倾向，不推定对方内心事实 |
| 传统婚配对象 | 原书妻占夫取官鬼、夫占妻取妻财 | 说明历史口径；现代关系不适配时以世应讨论，或先与用户约定代表关系 |
| 失物 | 钱与一般财物取妻财，证件衣物取父母，宠物取子孙 | 先固定类别，伏神仅供象义；搜索行动由最后见到地点等现实线索决定 |
| 问具体亲属 | 父母、兄弟、子孙等对应亲属 | 按问事人视角定关系，不能把代问者与被问者的位置混淆 |

传统事类依据 [用神章第八](https://zh.wikisource.org/wiki/增刪卜易/8)。现代职位、合同流程和双方互动是类比应用，应明确标记；“玄武＋财”不能当作盗窃证据。

用神多现：全部列出；结合问题指向，动静与日月旺衰说明主次。作为默认工作规则，一动一静先查动爻；同动或同静比较是否临日月、得生扶、空破及受制。不能仅凭“取旺”把实际问到的人或物换掉；两候选会给出不同结论时保留分支。原书 [八宫图后的入门示例](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy04.html) 有多父母爻的动静与旺衰取舍。

选择世爻或应爻时，固定该位置及其本位动变；即使变出另一六亲，也仍是该爻的变化。`moving_change_positions` 对世应选择只列本位发动的位置，对六亲类别选择才列各处动而变出该亲的位置。例如遁之姤世二午火化亥水，自占须保留这条回头克，不能因变成子孙就漏掉；别位变出与世同亲也不能替换世位。

用神不现：先看有关动爻变出之亲及日月是否为该类；变出之亲只在本位动变语境中使用。若仍不现，查看本宫纯卦相同位置的伏神。脚本会列出所有缺亲伏神，但不替代理解取用。《增删》[飞伏神章第二十八](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsny7d9s7d) 的日月取用、伏神与后段变爻讨论需一起看；单凭缺亲不能断“此事不存在”。

## 3. 建立四处依据，判断谁真正能生克

为主用神写四栏：**月建、日辰、卦中发动之爻、本位变爻**。每栏记生扶/克制、冲合、空破，以及当前是否能施力。不要把四栏机械计票或转成分数。

程序关系中优先读取 `direction_sentence` 的完整方向，例如“丑土生申金”。底层 `element_effect` 从 `source_branch` 视角命名：“申→丑”的“受生”表示申金受丑土生，不能误读成申日生丑土。五行方向是结构关系，实际施力还受以下层级限制；按此版本，诸爻不能伤日月，不能拿爻克日月当成日月受损或削弱其权力。

1. **月日先列已核计算关系。** 临月建或同五行、生扶，表示该体系的支持；月克与月冲分别记录，后者才叫月破。日生、日克、日合、日冲分别列。月生而日克、月克而日生时，两项同时保留，再查其他动变能否增扶或增克；“月一定大于日”不是通用裁决器。依据 [月将章第十六](https://zh.wikisource.org/wiki/增刪卜易/16) 和 [日辰章第十七](https://zh.wikisource.org/wiki/增刪卜易/17)。
2. **元忌是相对用神。** 生用神者元神，克用神者忌神，克元神并生忌神者仇神。程序给出 `role_elements` 与位置。它们与某六亲永久为吉凶不同；同一兄弟爻，问兄弟本人和问钱财，角色会变。依据 [第九章](https://zh.wikisource.org/wiki/增刪卜易/9)。
3. **有关系不等于有力量。** 元神或忌神发动后，仍查本身是否得日月帮助、是否受克、空破、变爻回克。旺而受生与衰而再受制应分别判断。元、忌同动还要查能否形成“忌生元、元生用”的连续生助；用神本身严重失陷时，不能只因元神出现就断获救。依据 [元神忌神衰旺章第十](https://zh.wikisource.org/wiki/增刪卜易/10)。
4. **变爻限制作用范围。** 按本章，变爻只对本位动爻论回头生克冲合；本位动爻与旁爻均不能反向生克变爻，日月可以作用变爻。脚本 `return_effect` 从变爻看本爻的五行关系，其中“受生／受克”仅记方向，不构成本爻反向施力。`moving_relations` 只列本卦动爻到其他本爻的结构。子月卯日坤之晋例中，四爻丑土可生本卦上爻酉金，不能生四爻变出的酉金；变爻巳火克本位酉金，又受子月之克。依据 [动变生克冲合章第十五](https://zh.wikisource.org/wiki/增刪卜易/15)。

完成标准：写出一条主要作用链和一条最强反证，例如“财得月扶，但元神发动化回头克，因此财源这条支持链暂不成立”。只有支持链没有反证的报告尚未审毕。

## 4. 空破、合冲与伏神的条件

| 结构 | 执行规则 | 不能省掉的条件 |
|---|---|---|
| 旬空 | 先保留当前空亡标记，再区分有支持可待时、还是失陷无救 | 旺动、得生与休囚受克不同；“动不为空”不是立即应事，出旬与填实另论 |
| 旬空又逢日冲 | 另查冲空，不直接套普通静爻暗动／日破二分 | 日辰章论冲空有用，但旬空章仍要求分辨有气待用与失陷；保留空亡、日冲、原始动静三个事实，再写能否起用的依据 |
| 月破 | 月支与爻支对冲即标月破 | 临日、得有效动变生扶与继续受克分开；不能直接等同永久无用 |
| 静爻日冲 | 旺相者可论暗动，休囚者可论日破 | 脚本仅标日冲；应以日月和动变的具体支持说明旺衰，不先贴结论 |
| 动爻日冲 | 保留发动，再查有力无力及变爻 | 不把一切日冲动爻都删成“散” |
| 合 | 分月日合、爻合、动化合以及全卦六合 | 合可能助起，也可能牵绊；见下方文本冲突规则 |
| 全卦六冲/六合 | 只作为结构变化参照 | 用神有无气、问的是成就还是解除，优先于“见合必成、见冲必败” |
| 伏神 | 从本宫纯卦原位取出所缺亲，检查其与飞神、日月、动爻的关系 | 飞生伏为支持；旺飞克伏为受制；飞空破可有引出条件，仍看伏自身是否有气 |

依据：[旬空章第二十六](https://zh.wikisource.org/wiki/增刪卜易/26)、[暗动章第二十二](https://zh.wikisource.org/wiki/增刪卜易/22)、[六合章第十九](https://zh.wikisource.org/wiki/增刪卜易/19)、[六冲章第二十](https://zh.wikisource.org/wiki/增刪卜易/20)、[飞伏神章](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsny7d9s7d)。旬空与月破定义另与 [《卜筮正宗》六甲旬空月破](https://www.quanxue.cn/qt_mingxiang/boshi/boshi17.html) 核对。

### 遇到冲突怎样裁决

这是本 skill 的工作次序，非古籍所载统一打分系统：

1. 先排除输入、历法、世应及本宫六亲错误；不拿象义掩盖错盘。
2. 保持问事取用，先看日月和动变作用能否成立，再看空破合冲是否限制作用；旺衰与动静相互核对，不以单一名词一票定局。
3. 具体作用链优先于全卦六冲/六合，六神最后作细节象义。原书 [六神章第十八](https://zh.wikisource.org/wiki/增刪卜易/18) 本身反对仅凭青龙白虎判吉凶。
4. 同一文本也有张力：第九章乾之小畜例把午化未相合解释为午火暂不能生父母；第十九章又概括动化合为“化扶”。因此本位化合保留**扶助**与**牵绊待解**的条件，不把其中一句当全局定律。若判断成败依赖此冲突，分别写“按此例／按一般条文”的结果与待观察条件。
5. 原书多次以再占处理疑难；本 skill 不为获得满意答案自动重抽。已有第二卦时说明取得原因、保留第一卦及原断；将多卦看作流派内比较，不能声称独立证实准确率。

## 5. 应期与落地

先说当下的主要推动与阻碍，随后才谈传统候选时点。旬空先区别出旬、值本支填实及对冲支冲空，三者不是同一时点；合绊可列出解除该合的冲支，月破可考察出月及得扶的条件。每个候选须回连“哪一爻、为何受限、何条件解除”，有救应的待用之空才谈相应窗口，不能为失陷无救的爻机械排“出空必成”。期限只到本周时，不任意把未满足的条件挪到明年。

脚本给出 `days_until_next_xun`，但不自动把某支换成现实日期。须由上层已核实日历换算后列候选日期；同一支每十二日重复，不能据此宣布唯一必应日。判断依赖**进退是否生效、墓绝、三合或具体应期**时，必须读[六爻动态条件](liuyao-dynamics.md)。程序只新增本位动变的七组进退配对，实际生效仍未判定；墓绝、成局和应期依该页原文条件核查，不能把“未计算”写成“不存在”。

客户正文按[大众版规范](reporting.md)先回答，再用两三条关键理由解释，列期限节点与有来源的现实建议。完整关系表、效力核查与版本比较留在摘要。涉及期内成败，按[完整期限核查](liuyao-dynamics.md#4-应期把候选日期系在已说明的机制上)检查起止与节点；缺公历日期等未核部分要限制主结论。化进、旬空、相冲均须经本版效力规则，不直接译成好事推进、没钱或受损。

## 6. 可复核占例：候文书得贲

原文：[飞伏神章第二十八，卯月壬辰日候文书](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsny7d9s7d)，[便于核图的现代排版转录](https://www.yanyilundao.com/b7/480)。这是书中故事，不是本 skill 的实测命中记录。

输入 `7 8 7 8 8 7`，卯月、壬辰日：山火贲，艮宫土，一世，世初应四，旬空午未。本卦无父母，艮纯卦二爻丙午父母伏在贲二爻丑土之下。

推理顺序：文书取父母 → 盘中不现、日月也不为父母 → 取二爻午火伏神 → 午火得卯木生，但当前午未空 → 将“有传统支持”与“当下未现”分开。原书所记候选是甲午出空；不能以伏神出现就直接断今天收到。该例已入测试，验证卦、宫、世应、伏神位置与空亡；不验证原书的应验叙事。

正式报告按[大众版规范](reporting.md)先回答再解释，参照 [客户示范](liuyao-example.md) 的详略。示例的原判与模拟回访均保留，不将事后解释写成事前命中。
